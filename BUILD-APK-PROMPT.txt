Build HOPE as a production Android APK.

Use Flutter Stable 3.47.x and JDK 17. From the repository root:
1) flutter clean
2) flutter pub get
3) flutter analyze
4) flutter test
5) verify API_BASE_URL is a real HTTPS production API URL
6) verify ANDROID_RELEASE_STORE_FILE, ANDROID_RELEASE_STORE_PASSWORD, ANDROID_RELEASE_KEY_ALIAS, ANDROID_RELEASE_KEY_PASSWORD are present
7) run: flutter build apk --release --dart-define=API_BASE_URL=https://YOUR_API_HOST/api/v1
8) verify build/app/outputs/flutter-apk/app-release.apk exists
9) verify package com.hope.marketplace, minSdk 30, targetSdk 36
10) compute SHA-256
11) never claim a build is signed/publishable without a real release keystore
12) report Flutter version, analyze/test results, API URL, signing status, APK path, and SHA-256.
